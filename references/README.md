# Fuentes y diccionario

La fuente primaria será una exportación manual de un grupo de WhatsApp o Telegram. El registro local `data/raw/source.json` guarda la plataforma, la fecha de registro y las huellas SHA-256 del archivo original y su copia. Se omite de Git porque el nombre del archivo podría identificar al grupo.

Cuando conozcamos el formato real, documentaremos aquí las columnas tidy, sus tipos, reglas de anonimización y decisiones de limpieza sin incluir nombres ni contenido privado.
